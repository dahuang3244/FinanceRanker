================================================================
 FinanceRanker — 第一次使用请先看这里
================================================================

这是一个免安装的 Windows 程序。不需要装 Python，也不需要装任何东西。


----------------------------------------------------------------
 怎么用
----------------------------------------------------------------

1. 把整个 FinanceRanker 文件夹解压到任意位置
   （例如桌面，或者 D:\FinanceRanker）

2. 双击文件夹里的 FinanceRanker.exe

3. 浏览器会自动打开一个标签页，显示程序界面

   注意：不要移动或删除 _internal 文件夹，
         它和 exe 是一体的，缺了程序就打不开。


----------------------------------------------------------------
 里面已经带好一份数据
----------------------------------------------------------------

这份拷贝已经预先抓取过 15 只股票，打开就能直接看到排名、
公司明细以及 GAAP → 调整后 EPS 调节表，不用等。

想换成最新数据，点左侧菜单的「抓取与排名」（Fetch and rank）：

  · 15 只股票大约需要 2–4 分钟
  · 进度会实时显示在页面上

数据存在 exe 同级的 data 文件夹里，跟着这个文件夹一起走：
  · 删掉 data 文件夹 = 恢复出厂状态（下次要重新抓取）
  · 把整个文件夹拷给别人 = 连同数据一起分享
  · 如果程序放在只读位置（例如 Program Files），
    数据会自动改存到 %LOCALAPPDATA%\FinanceRanker


----------------------------------------------------------------
 需要联网
----------------------------------------------------------------

程序从这些公开数据源取数，请确保网络能访问：

  · SEC EDGAR（美国证监会财报）
  · 新浪财经 / 腾讯 / 东方财富（行情）
  · Yahoo Finance（分析师预期、复权价格）
  · CBOE（期权链，仅在打开「期权环境」时需要）

如果某个数据源暂时不通，程序会自动换用备用源，
并在「数据源」页面标出哪一个可用、哪一个不可用。


----------------------------------------------------------------
 关于数据
----------------------------------------------------------------

· 数据全部实时抓取自公开来源，随包附带的快照只是抓取结果
· 数据与缓存存放在 exe 同级的 data 文件夹
  （只读位置则退回 %LOCALAPPDATA%\FinanceRanker）
· 分数是「同一批股票内部的相对分位」，不是绝对质量评分。
  换一批对比标的，同一个分数会变化
· 卖方分析师的数据是第三方观点，不参与打分，只作参考
· 非 GAAP EPS 优先取自公司财报新闻稿里自己披露的调节口径
  （例如股权投资收益的税后影响、不可抵扣的罚款）；
  只有在找不到披露时，才由本程序按 XBRL 重算。
  明细里每一行都标注了它来自哪个来源
· 各家公司口径不同，跨公司比较仅供参考
· 这不是投资建议


----------------------------------------------------------------
 功能
----------------------------------------------------------------

· 总览 / 抓取与排名：15 只美股按 40+ 指标分位打分排名
· 数据预览：单只股票每个参数的计算过程
· 公司明细：五个维度得分、GAAP → 调整后 EPS 调节表、
  公司大事记（SEC 8-K / 6-K 申报事件）与催化剂表
· 市场分析师：目标价、评级分布、财报超预期
· 期权环境：任意美股代码的 Put/Call 结构、Max Pain、
  持仓集中区、异动合约、Gamma 敞口与隐含波动率
  （左侧菜单里，需联网读取期权链）

期权数据来自 CBOE 官方延迟报价，包含希腊字母与 IV，
因此可以计算做市商 Gamma 敞口和 IV/实际波动率。
若 CBOE 取不到而退回 Yahoo，两者都会省略而不是估算——
Yahoo 的 IV 是占位值，且不提供希腊字母。

Gamma 敞口使用「做市商持有 Call、卖出 Put」的行业惯例假设。
真实的做市商持仓无法从公开数据得知，所以界面上每一项都标注了
这个前提，它是惯例推算，不是观测值。

无风险利率取自美国财政部每日发布的国债收益率曲线（总览页）。


----------------------------------------------------------------
 数据来源与合规（重要）
----------------------------------------------------------------

本项目分发代码，不分发数据；数据由使用者按各来源自身的条款获取。

公开数据源与其条款状况：

  · SEC EDGAR（财报、XBRL、8-K）—— 官方公开数据，可商用
  · 美国财政部（国债收益率曲线）—— 官方公开数据，可商用
  · 新浪 / 腾讯 / 东方财富 —— 行情与基本面；条款未核实，
    走公开接口，请遵守各站条款
  · Yahoo Finance —— 分析师预期、财报日历；仅限个人使用
  · CBOE 官方延迟报价 —— 期权链与希腊字母。数据为延迟行情。
    注意：Cboe 的 Use of Content 政策要求商业使用或再分发前
    取得书面授权。个人研究可以，商用请先向 Cboe 申请。

分发方式不改变条款：把安装包发给别人，和把服务挂成公开网址，
数据都来自同一批来源，约束相同。区别在于用途与对象——个人、
少量的研究用途，与对外提供公开服务（尤其商用），在多数条款下
是两种情形。公开网址更接近「分发」，更容易触及需要授权的门槛，
但发送安装包并不等于自动合规。

商用前请逐一核对上述来源的现行条款，尤其是 CBOE 与 Yahoo。
本程序按「原样」提供，不对数据源的可用性、准确性或授权状态作担保。

----------------------------------------------------------------
 打不开怎么办
----------------------------------------------------------------

1. 确认 _internal 文件夹还在，且和 exe 在同一层

2. 如果双击没反应，看看这个日志文件（就在 exe 同级的 data 文件夹里）：
     FinanceRanker\data\launcher.log
   （若程序放在只读位置，则见 %LOCALAPPDATA%\FinanceRanker\launcher.log）

3. 如果提示端口被占用，关掉程序重开即可
   （程序会自动选一个空闲端口，一般不会冲突）

4. Windows Defender 可能对未签名的 exe 提示警告。
   点「更多信息」→「仍要运行」即可。
   这个程序没有代码签名，所以会触发提示。
